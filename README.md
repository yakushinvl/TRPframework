# Сервис учёта выступлений студентов

Веб-приложение на Django для учёта выступлений студентов на научных конференциях и фиксации результатов.

Репозиторий проекта: https://github.com/yakushinvl/TRPframework

## Страницы веб-интерфейса
* `/` — главная страница: описание сервиса и навигация;
* `/presentations/` — список выступлений студентов;
* `/presentations/<int:presentation_id>/` — детальная страница выступления;
* `/events/` — список мероприятий и регламент;
* `/events/<int:event_id>/` — детальная страница мероприятия.

При обращении к несуществующему адресу возвращается страница с ошибкой 404.

## Структура проекта
* `manage.py` — управление проектом Django;
* `tracker/` — конфигурация Django-проекта (`settings.py`, `urls.py`);
* `homepage/` — приложение главной страницы и обработчик 404;
* `events/` — приложение для отображения мероприятий;
* `presentations/` — приложение для отображения выступлений;
* `models/` — классы предметной области (`Student`, `Event`, `Presentation`);
* `storage.py` — загрузка данных из JSON-файлов;
* `data/` — файлы данных в формате JSON;
* `tests/` — автоматизированные тесты pytest.

## Запуск приложения

1. Установка зависимостей:
```bash
pip install -r requirements.txt
```

2. Запуск сервера разработки:
```bash
python manage.py runserver
```

После запуска приложение доступно по адресу: http://127.0.0.1:8000/

## Запуск тестов
```bash
pytest
```
