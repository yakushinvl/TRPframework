# Сервис учёта выступлений студентов

Консольное приложение для учёта выступлений студентов на мероприятиях и фиксации результатов (объектная модель).

Репозиторий проекта: https://github.com/yakushinvl/TRPframework

## Основные классы
- `Student` — студент (id, name, group);
- `Event` — мероприятие (id, name, max_duration);
- `Presentation` — выступление (связывает объекты `Event` и `Student`, содержит тему, время, оценки, итоговый балл и наградной статус).

## Основные операции
- добавление и просмотр мероприятий;
- добавление и просмотр студентов;
- создание выступлений со связью с мероприятиями и студентами;
- проверка регламента времени и расчет результатов;
- поиск выступлений по имени студента;
- сортировка выступлений по баллам;
- сохранение и загрузка объектов из JSON.

## Структура проекта
- `main.py` — точка запуска и консольное меню;
- `models/` — пакет классов предметной области (`Student`, `Event`, `Presentation`);
- `storage.py` — сохранение и загрузка объектов в JSON;
- `utils.py` — безопасный ввод чисел;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты pytest.

## Требования
- Python 3.10+
- pytest
- flake8

Установка зависимостей:
```bash
pip install -r requirements.txt
```

## Запуск программы
```bash
python main.py
```

## Запуск тестов
```bash
pytest
```
