# сервис учёта выступлений студентов

веб-приложение для учёта выступлений студентов на мероприятиях и фиксации результатов

## возможности
- просмотр мероприятий и карточки мероприятий по slug
- просмотр выступлений с фильтрацией по мероприятиям, студентам, статусам и регламенту
- сортировка выступлений по времени, теме, студенту и мероприятию
- пагинация страниц списка выступлений
- страница статистики мероприятий и докладов (агрегация и аннотирование)
- модели django orm, связи ForeignKey, миграции и менеджер запросов
- статусы выступлений (активно, завершено, отменено) через TextChoices
- вычисляемые поля GeneratedField в базе данных
- административная панель django с поиском, фильтрацией, редактированием, inline-формами и действиями
- отладка sql-запросов через django debug toolbar
- глобальный контекст-процессор с подсчётом мероприятий

## структура проекта
- manage.py — запуск проекта
- tracker/ — настройки django и отладочная панель
- homepage/ — главная страница
- events/ — приложение мероприятий (модель Event, slug, GeneratedField, context_processors)
- students/ — приложение студентов (модель Student)
- presentations/ — приложение выступлений (модель Presentation, статусы, QuerySet)
- templates/ — шаблоны страниц
- sql/ — схема бд и sql-запросы (пр7)
- db/ — скрипты инспекции и переноса данных в orm
- data/ — исходная база данных sqlite и json-файлы
- tests/ — тесты pytest

## запуск
```bash
python manage.py migrate
python manage.py runserver
```

вход в админку: http://127.0.0.1:8000/admin/ (логин: admin, пароль: admin)

## тесты
```bash
pytest
```
