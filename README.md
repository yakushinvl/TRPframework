# сервис учёта выступлений студентов

веб-приложение для учёта выступлений студентов на мероприятиях и фиксации результатов

## возможности
- просмотр мероприятий
- просмотр выступлений
- карточки мероприятий и выступлений
- поиск выступлений по теме и студенту
- страница статистики мероприятий и докладов
- база данных sqlite и sql-запросы
- проверка регламента времени
- подсчёт баллов и наград

## структура проекта
- manage.py — запуск проекта
- tracker/ — настройки django
- homepage/ — главная страница
- events/ — мероприятия
- presentations/ — выступления и статистика
- templates/ — шаблоны страниц
- models/ — классы студент, мероприятие, выступление
- sql/ — схема бд и sql-запросы
- db/ — подключение к sqlite и импорт данных
- data/ — база данных и файлы json
- tests/ — тесты pytest

## запуск
```bash
python -m db.import_json
python manage.py runserver
```

## тесты
```bash
pytest
```
