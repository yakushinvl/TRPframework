# Сервис учёта выступлений студентов

## Назначение
Сервис для учёта выступлений студентов на мероприятиях и фиксации результатов.

## Целевая аудитория
Студенты и преподаватели.

## Предметная область
Учёт выступлений студентов на мероприятиях.

## Основные сущности
- Студент
- Мероприятие
- Выступление
- Результат

## Основные функции
- Проверка времени выступления
- Подсчёт общего балла
- Определение результата

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
