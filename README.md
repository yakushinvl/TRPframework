# Сервис учёта выступлений студентов

Консольное приложение для учёта выступлений студентов на мероприятиях и фиксации результатов.

## Возможности
- просмотр и добавление мероприятий;
- просмотр и добавление выступлений студентов;
- проверка регламента времени выступления;
- автоматический расчет баллов и определение наградного места;
- поиск выступлений по студенту;
- сортировка выступлений по баллам;
- сохранение и загрузка данных из JSON.

## Структура проекта
- `main.py` — точка запуска и консольное меню;
- `events.py` — функции работы с мероприятиями;
- `presentations.py` — функции работы с выступлениями;
- `storage.py` — функции загрузки и сохранения данных (JSON);
- `utils.py` — функции безопасного ввода чисел;
- `data/` — каталог с файлами данных (`events.json`, `presentations.json`);
- `tests/` — автоматизированные тесты pytest.

## Требования
- Python 3.10+
- pytest
- flake8

Установка зависимостей:
```bash
pip install -r requirements.txt
```

## Запуск программы
```bash
python main.py
```

## Запуск тестов
```bash
pytest
```
